# amanuma - ゲームルール

> 本ドキュメントは Phaser 版時代の「スリーセブン」ルール (Phase 1/2) を保存しつつ、
> PixiJS 移植 (Phase 3) で追加・変更された箇所を冒頭にまとめる。

## Phase 3 (PixiJS 版) で変更された点

| 項目 | Phaser 版 | PixiJS 版 |
|---|---|---|
| 開始時の盤面 | 空盤面 | **お題型** (1・2 主体 + ターゲット 7 が配置済) |
| クリア条件 | (なし、無限プレイ) | **盤面のターゲット 7 をすべて消す** (`status='cleared'`) |
| 落下挙動 | 一定速度 | **水中物理** (浮力 + 粘性減衰) でふわっと沈む |
| 着水 | 即固定 | **横揺れ + 水面波紋 + 泡** |
| 消去演出 | フェード | **半透明気泡数個** が水面に向けゆっくり上昇 |
| 対戦の P1 / P2 入力 | WASD と矢印 | **同一の矢印キー (P1 のみ操作可)**。P2 は未割当 (CPU/AI/ネットは未実装) |
| お邪魔ブロック | 連鎖ボーナス付き | 消去 N 個で `floor(N/3)` 個送信 (MVP) |
| シーン遷移 | カメラフェード | **宇宙誌面パン＆ズーム** (cubicInOut tween) |
| 音 | 未実装 | **SoundManager** + ミュート永続化、アセット未投入でも graceful |
| 数字の出現確率 | 1〜6 各 17% / 7 = 2% (= 104%) | **7 = 2% / 1〜6 は残り 98% を均等** (正規化) |

## 概要 (Phaser 版当時の記述)

幽遊白書に登場した天沼月人のパズルゲーム「スリーセブン」を再現。

## 基本ルール

### フィールド

- 5列 x 10行のグリッド
- ブロックは上から1つずつ落下

### 消去条件

縦または横に連続したブロックの合計が **7** になると消える。

**例:**

- `2 + 5 = 7`
- `3 + 4 = 7`
- `1 + 2 + 4 = 7`
- `1 + 1 + 1 + 1 + 1 + 1 + 1 = 7`

### 7の特別ルール

**7のブロックは3つ以上並ばないと消えない。**

- `7 + 7` → 消えない
- `7 + 7 + 7` → 消える（合計21だが、3つ以上で特別消去）

### 重力

ブロック消去後、上にあるブロックが落下して空白を埋める。

### 連鎖

落下後に新たに合計7になる組み合わせがあれば自動消去。連鎖ボーナスあり。

## スコアリング

| アクション   | 得点          |
| ------------ | ------------- |
| ブロック消去 | 消去数 × 10点 |
| 連鎖ボーナス | 連鎖数 × 50点 |

## レベルシステム

- 10回消去ごとにレベルアップ
- レベルに応じて落下速度が上昇（最大2倍速）

## 数字の出現確率

- 1〜6: 各約17%
- 7: 約2%（希少）

## 操作方法

### シングルプレイ

| キー | 動作       |
| ---- | ---------- |
| ← →  | 左右移動   |
| ↓    | 高速落下   |
| P    | 一時停止   |
| R    | リスタート |
| ESC  | タイトルへ |

### 対戦モード

**Player 1 (左側)**
| キー | 動作 |
|------|------|
| A / D | 左右移動 |
| S | 高速落下 |

**Player 2 (右側)**
| キー | 動作 |
|------|------|
| ← → | 左右移動 |
| ↓ | 高速落下 |

**共通**
| キー | 動作 |
|------|------|
| P | 一時停止 |
| R | リスタート |
| ESC | タイトルへ |

## 対戦モード - 攻撃システム

- ブロック消去時、相手に「お邪魔ブロック」を送信
- お邪魔ブロック数 = 消去ブロック数 ÷ 3（最低1個）
- 連鎖時は連鎖数に応じて増加
- お邪魔ブロックは最下行に追加され、フィールドが1行上に押し上げられる

## 勝敗条件

- シングル: フィールドが一杯になったらゲームオーバー
- 対戦: 先にフィールドが一杯になった方が負け
