# スリーセブン - ゲームルール

## 概要

幽遊白書に登場した天沼月人のパズルゲーム「スリーセブン」を再現。

## 基本ルール

### フィールド

- 5列 x 10行のグリッド
- ブロックは上から1つずつ落下

### 消去条件

縦または横に連続したブロックの合計が **7** になると消える。

**例:**
- `2 + 5 = 7`
- `3 + 4 = 7`
- `1 + 2 + 4 = 7`
- `1 + 1 + 1 + 1 + 1 + 1 + 1 = 7`

### 7の特別ルール

**7のブロックは3つ以上並ばないと消えない。**

- `7 + 7` → 消えない
- `7 + 7 + 7` → 消える（合計21だが、3つ以上で特別消去）

### 重力

ブロック消去後、上にあるブロックが落下して空白を埋める。

### 連鎖

落下後に新たに合計7になる組み合わせがあれば自動消去。連鎖ボーナスあり。

## スコアリング

| アクション | 得点 |
|-----------|------|
| ブロック消去 | 消去数 × 10点 |
| 連鎖ボーナス | 連鎖数 × 50点 |

## レベルシステム

- 10回消去ごとにレベルアップ
- レベルに応じて落下速度が上昇（最大2倍速）

## 数字の出現確率

- 1〜6: 各約17%
- 7: 約2%（希少）

## 操作方法

### シングルプレイ

| キー | 動作 |
|------|------|
| ← → | 左右移動 |
| ↓ | 高速落下 |
| P | 一時停止 |
| R | リスタート |
| ESC | タイトルへ |

### 対戦モード

**Player 1 (左側)**
| キー | 動作 |
|------|------|
| A / D | 左右移動 |
| S | 高速落下 |

**Player 2 (右側)**
| キー | 動作 |
|------|------|
| ← → | 左右移動 |
| ↓ | 高速落下 |

**共通**
| キー | 動作 |
|------|------|
| P | 一時停止 |
| R | リスタート |
| ESC | タイトルへ |

## 対戦モード - 攻撃システム

- ブロック消去時、相手に「お邪魔ブロック」を送信
- お邪魔ブロック数 = 消去ブロック数 ÷ 3（最低1個）
- 連鎖時は連鎖数に応じて増加
- お邪魔ブロックは最下行に追加され、フィールドが1行上に押し上げられる

## 勝敗条件

- シングル: フィールドが一杯になったらゲームオーバー
- 対戦: 先にフィールドが一杯になった方が負け
