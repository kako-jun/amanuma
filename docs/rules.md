# amanuma - ゲームルール

PixiJS v8 + Vite + TypeScript で実装した水中落ち物パズル (Phase 3) の現行ルール。

## 概要

旧 Phaser 版「スリーセブン」(幽遊白書 天沼月人のパズルゲーム再現) を、PixiJS 移植にあわせて
ビーカー内の水中落ち物パズル + お題型クリアに刷新したもの。

## 基本ルール

### フィールド

- 5列 × 10行のグリッド (ビーカー内部)
- 上から 1 つずつブロックが落下し、水中物理で「ふわっと」沈む
- 開始時の盤面は **お題型**: 1・2 主体のブロックと配置済みのターゲット 7 がすでに積まれている (空盤面ではない)

### 消去条件

縦または横に連続したブロックの合計が **7** になると消える。

例:
- `2 + 5 = 7`
- `3 + 4 = 7`
- `1 + 2 + 4 = 7`
- `1 + 1 + 1 + 1 + 1 + 1 + 1 = 7`

### 7 の特別ルール

**7 のブロックは 3 つ以上連続** しないと消えない。

- `7 + 7` → 消えない
- `7 + 7 + 7` → 消える (3 つ以上で特別消去)

### 重力 (Phase 3 = 水中物理)

ブロック消去後、上のブロックが落下して空白を埋める。落下中ブロックの挙動は
[`UnderwaterPhysics.ts`](../src/physics/UnderwaterPhysics.ts) 参照:

- 重力 18 row/s²、浮力 6 row/s²、粘性減衰係数 1.6 [1/s]
- 終端速度 ≈ 7.5 row/s で「ふわっと」沈む

### 連鎖

落下後に新たに合計 7 になる組み合わせがあれば自動消去 (Promise チェーン)。連鎖段数に応じて得点ボーナス。

## スコアリング

| アクション | 得点 |
|---|---|
| ブロック消去 | 消去数 × 10 点 |
| 連鎖ボーナス | 連鎖段数 × 50 点 |

実装は [`ChainRunner.runChain()`](../src/game/ChainRunner.ts)。

## クリア条件

### シングルプレイ

- **盤面のターゲット 7 がすべて消える** と `status='cleared'` で Result シーンに遷移
- スポーン位置 (中央列の最上段) が埋まっている状態で新ブロックを生成しようとすると `gameover`

(Phase 1/2 にあった「フィールドが一杯になったらゲームオーバー」「レベルシステム (落下加速)」「ハイスコア
localStorage 保存」は Phase 3 では未実装。代わりにお題型クリアで完結する設計)

### 対戦モード

- 両プレイヤーが **同じ初期お題** からスタート
- 先に `cleared` (ターゲット 7 全消し) に到達した方が勝ち
- 途中で `gameover` になった方は負け
- **P1 のみ手動操作可** (キーボード・タッチ)、P2 はキー未割当のため自動落下で沈み続ける (CPU AI / ネット対戦は未実装、TODO)

## 数字の出現確率

実装は [`randomBlocks.generateBlockValue()`](../src/game/randomBlocks.ts):

| 値 | 確率 |
|---|---|
| 7 | 2 % |
| 1〜6 | 各 (98% ÷ 6) ≒ 16.33 % |

旧仕様 (1〜6 各 17% + 7 = 2% で合計 104%) は破綻していたため、Phase 3 で正規化した。

## 操作方法

### キーボード (シングル / 対戦の P1 共通)

| キー | 動作 |
|---|---|
| ← / → | 左右移動 |
| ↓ | 高速落下 |
| P | 一時停止トグル |
| R | リスタート |
| M | ミュート切替 |
| 1 / 2 | タイトル画面でシングル / 対戦選択 |
| Enter / Space | 確定 (タイトル / Result) |
| Esc | タイトルへ戻る (Result 画面のみ。ゲーム中の Esc は現状未割当) |

### タッチ

| 操作 | 動作 |
|---|---|
| canvas 左半分タップ | 左移動 |
| canvas 右半分タップ | 右移動 |
| 下スワイプ (50px+) | 高速落下 |

バーチャルパッド (半透明十字キー) は採用せず、画面エリアそのものに意味を持たせる方針 (kako-jun 指定)。

## 対戦モード - お邪魔ブロックシステム (MVP)

- 自分が連鎖の各ステップで消去した N 個に対し、相手に `floor(N/3)` 個のお邪魔ブロックを送信
  - N < 3 のステップは送信なし (= 最低 1 個保証なし)
- 受け取った側は **上の空セル** に `1..6` のランダム値を埋める
  ([`PlayerBoard.garbageReceived()`](../src/scenes/PlayerBoard.ts) 実装)
- 相手が連鎖中 (`isChaining=true`) のときは送信を破棄 (キューイング不在、要改善)
- 連鎖段数による倍率は未実装、TODO

(Phase 2 にあった「お邪魔は最下行に追加してフィールドを 1 行押し上げる」方式は Phase 3 では採用していない)
