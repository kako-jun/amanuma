# スリーセブン - ゲーム設計

## ゲームルール

### 基本ルール

1. **フィールド**: 5列 × 10行
2. **ブロック**: 1〜7の数字が1つずつ落下
3. **消去条件**: 縦または横に連続したブロックの合計が7になると消える
   - 例: `2+5`, `3+4`, `1+2+4`, `1+1+1+1+1+1+1`
4. **特別ルール**: 7のブロックは3つ以上並ばないと消えない
5. **重力**: ブロック消去後、上のブロックが落下

### スコアリング

- 基本: 消去したブロック数 × 10点
- 連鎖: 実装予定（連鎖数に応じてボーナス）

### 主要クラス: MainScene

#### プロパティ

- `board: number[][]` - ゲームボード（0=空、1-7=数字）
- `currentBlock` - 現在落下中のブロック
- `score: number` - 現在のスコア
- `dropInterval: number` - 落下速度（1000ms）
- `gameOver: boolean` - ゲームオーバーフラグ

#### 主要メソッド

1. `spawnBlock()` - 新しいブロックを生成
2. `collision(offsetX, offsetY)` - 衝突判定
3. `merge()` - ブロックをボードに固定
4. `drop()` - ブロックを1マス下に移動
5. `move(dir)` - 左右移動
6. `checkAndClearSevens()` - 合計7のチェックと消去
7. `applyGravity()` - 重力適用
8. `draw()` - 描画

### アーキテクチャ（実装済み）

**GameBoardクラス**
- 1人分のゲームロジックをカプセル化
- プロパティ: board, currentBlock, nextBlock, score, level, etc.
- メソッド: spawnBlock(), drop(), collision(), checkAndClearSevens(), addGarbageBlocks()
- シングルプレイ・対戦モード両方で使用可能

**VersusScene**
- 2つのGameBoardインスタンスを管理
- 各プレイヤーの入力処理
- 攻撃システムの実装
- 勝敗判定

### 攻撃システム（実装済み）

- ブロック消去時、相手にお邪魔ブロックを送信
- お邪魔ブロック数 = 消去ブロック数 ÷ 3（最低1個）
- 連鎖時は連鎖数に応じて増加
- お邪魔ブロックは最下行にランダムに追加され、フィールド全体が1行上に押し上げられる

### 勝敗条件（実装済み）

- 相手のフィールドが一杯になったら（ゲームオーバー）勝ち
- 勝者が大きく表示される
- R キーでリスタート、ESC キーでタイトルへ戻る
