# スリーセブン - ゲーム設計

## ゲームルール

### 基本ルール

1. **フィールド**: 5列 × 10行
2. **ブロック**: 1〜7の数字が1つずつ落下
3. **消去条件**: 縦または横に連続したブロックの合計が7になると消える
   - 例: `2+5`, `3+4`, `1+2+4`, `1+1+1+1+1+1+1`
4. **特別ルール**: 7のブロックは3つ以上並ばないと消えない
5. **重力**: ブロック消去後、上のブロックが落下

### スコアリング

- 基本: 消去したブロック数 × 10点
- 連鎖: 実装予定（連鎖数に応じてボーナス）

### 主要クラス: MainScene

#### プロパティ

- `board: number[][]` - ゲームボード（0=空、1-7=数字）
- `currentBlock` - 現在落下中のブロック
- `score: number` - 現在のスコア
- `dropInterval: number` - 落下速度（1000ms）
- `gameOver: boolean` - ゲームオーバーフラグ

#### 主要メソッド

1. `spawnBlock()` - 新しいブロックを生成
2. `collision(offsetX, offsetY)` - 衝突判定
3. `merge()` - ブロックをボードに固定
4. `drop()` - ブロックを1マス下に移動
5. `move(dir)` - 左右移動
6. `checkAndClearSevens()` - 合計7のチェックと消去
7. `applyGravity()` - 重力適用
8. `draw()` - 描画

### 消去ロジック

```typescript
// 横方向と縦方向をそれぞれチェック
// 連続したブロックの合計が7になるか判定
// 全て7の場合 → 3つ以上必要
// 7以外が含まれる → 通常通り消去
```

### 攻撃システム

- 1ライン消去 → 相手に1行追加
- 2ライン同時消去 → 相手に2行追加
- 連鎖 → 連鎖数×1行追加

### 勝敗条件

- 相手のフィールドが一杯になったら勝ち
- 先に3ゲーム先取で最終勝利
