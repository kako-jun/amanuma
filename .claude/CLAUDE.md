# amanuma - スリーセブン開発プロジェクト

## プロジェクト概要

幽遊白書に登場した天沼月人のパズルゲーム「スリーセブン」を再現するプロジェクト。

## 技術スタック

- **フレームワーク**: React 18 + Vite 6
- **言語**: TypeScript 5
- **ゲームエンジン**: Phaser 3.87.0
- **スタイリング**: Tailwind CSS 4

## 開発フェーズ

### Phase 1: 1人用シングルプレイ版（現在）
- 基本ゲームシステムの実装
- スリーセブンルールの実装
- UI/UXの改善

### Phase 2: 2人対戦版（将来）
- 横画面レイアウト
- 左右のキーボードでの2人操作
- 攻撃システム（ライン消去時に相手にブロック送信）
- ネットワーク通信なし（ローカル対戦のみ）
