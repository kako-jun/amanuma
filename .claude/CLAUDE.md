# amanuma - スリーセブン

幽遊白書に登場した天沼月人のパズルゲーム「スリーセブン」を再現。

## 技術スタック

- React 18 + Vite 6 + TypeScript 5
- Phaser 3.87.0
- Tailwind CSS 4

## クイックスタート

```bash
npm install
npm run dev    # http://localhost:3000
```
