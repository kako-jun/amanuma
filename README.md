# amanuma

React + Vite + TypeScriptで作成した「スリーセブン」パズルゲーム

## 🎮 概要

「幽遊白書」に登場したパズルゲーム「スリーセブン」の再現です。Phaser 3ゲームエンジンを使用して作られています。

## ✨ 特徴

- React 18 + Vite 6による高速な開発環境
- TypeScript 5による型安全なコード
- Phaser 3ゲームエンジン
- Tailwind CSS 4によるスタイリング
- GitHub Pagesへの自動デプロイ

## 🎲 ゲームルール

1. **ブロックの種類**: 1〜7の数字が書かれたブロックが落ちてきます
2. **消去条件**: 縦または横に並んだブロックの合計が**7**になると消えます
   - 例: 2+5, 3+4, 1+2+4, 1+1+1+1+1+1+1 など
3. **7の特別ルール**: 数字の「7」のブロックだけは、**3つ並べないと消えません**
4. **フィールド**: 5列×10行

## 🎯 操作方法

- ⬅️➡️ 左右矢印キー：ブロックの移動
- ⬇️ 下矢印キー：ブロックの高速落下

## 🚀 開発

### 必要な環境

- Node.js 20以上
- npm

### インストール

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

### ビルド

```bash
npm run build
```

### プレビュー

```bash
npm run preview
```
