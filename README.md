# amanuma

React + Vite + TypeScriptで作成した「スリーセブン」パズルゲーム

## 🎮 概要

「幽遊白書」に登場したパズルゲーム「スリーセブン」の再現です。Phaser 3ゲームエンジンを使用して作られています。

## ✨ 特徴

- React 18 + Vite 6による高速な開発環境
- TypeScript 5による型安全なコード
- Phaser 3ゲームエンジン
- Tailwind CSS 4によるスタイリング
- GitHub Pagesへの自動デプロイ

## 🎲 ゲームルール

1. **ブロックの種類**: 1〜7の数字が書かれたブロックが落ちてきます
2. **消去条件**: 縦または横に並んだブロックの合計が**7**になると消えます
   - 例: 2+5, 3+4, 1+2+4, 1+1+1+1+1+1+1 など
3. **7の特別ルール**: 数字の「7」のブロックだけは、**3つ並べないと消えません**
4. **フィールド**: 5列×10行

## 🎯 操作方法

### タイトル画面
- 1 キーまたはクリック：シングルプレイ
- 2 キーまたはクリック：対戦モード

### シングルプレイ
- ⬅️➡️ 左右矢印キー：ブロックの移動
- ⬇️ 下矢印キー：ブロックの高速落下
- P キー：一時停止/再開

### 対戦モード（2人同時プレイ）
- **Player 1**: W/A/S/D キー（A:左、D:右、S:高速落下）
- **Player 2**: 矢印キー（←:左、→:右、↓:高速落下）
- P キー：一時停止/再開

### ゲームオーバー時
- R キー：ゲームを再開
- ESC キー：タイトル画面に戻る

## ✨ 実装済み機能

### Phase 1: シングルプレイモード ✅
- 🎮 **タイトル画面**：モード選択、ハイスコア表示
- 🎲 **1-7の数字ブロック**：確率調整（7は2%で出現）
- ➕ **合計7で消去**：7だけは3つ必要
- ⛓️ **連鎖システム**：連鎖ボーナス付き
- 👁️ **ネクストブロック表示**：次のブロックを予告
- 🔄 **リスタート機能**：Rキーで即座に再開
- 🏆 **ハイスコア記録**：ブラウザに永続保存
- ⏸️ **一時停止機能**：Pキーでいつでも一時停止
- 📈 **レベルシステム**：難易度自動調整（最大2倍速）
- 🎨 **スムーズな操作感**：メモリリーク対策済み

### Phase 2: 対戦モード ✅
- 🆚 **2人同時プレイ**：横画面で2つのフィールド
- ⌨️ **デュアル操作**：P1はWASD、P2は矢印キー
- ⚔️ **攻撃システム**：ブロック消去で相手にお邪魔ブロック送信
- 🏁 **勝敗判定**：先にゲームオーバーした方が負け
- ⛓️ **連鎖攻撃**：連鎖すると大量のお邪魔ブロックを送信

## 🚀 開発

### 必要な環境

- Node.js 20以上
- npm

### インストール

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

### ビルド

```bash
npm run build
```

### プレビュー

```bash
npm run preview
```
